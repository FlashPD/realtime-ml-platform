# v0.1.0 — Batch training and online serving

Prepared release candidate; the maintainer owns commits, tagging and GitHub publication.

This release carries NYC TLC data through validated ingestion, point-in-time features, three-model
evaluation, guarded MLflow promotion, FastAPI serving on Kubernetes, acknowledged prediction
publication, and Prometheus/Grafana monitoring.

- Static model: **187.18 s MAE**, **25.78% below baseline**, evaluated on 3,419,441 April trips
  after training on 9,316,058 January–March trips; all fixed gates passed.
- Local kind load: **10,000 successes at 100 requests/s**, **7.99 ms client P95**, no errors/drops;
  all 10,020 measured/warm-up broker events matched.
- Isolated broker failure: **120 explicit 503s**, acknowledgment recovered in **6.25 s**, unchanged
  API process, all 4,040 baseline/recovery benchmark events matched.
- Portable model/evidence archive, Python dependency snapshot, clean-checkout verification,
  concise walkthrough and full rebuild instructions.

## Assets

`tripml-batch-v0.1.0-artifacts.tar.gz` and its `.sha256` sidecar contain the original model,
April workload and raw measured evidence. `tripml-batch-v0.1.0-source.tar.gz` is generated from
the final tag by the maintainer. Model/data attribution follows the repository's data card;
source code is MIT licensed. Follow the [reproduction runbook](../runbooks/reproduce-release.md).

## Boundaries

The selected model uses static features and completed-trip distance. These results do not establish
pre-trip ETA accuracy, production capacity, high availability, exactly-once delivery, or live
streaming correctness. Failure traffic was lower than the primary load. Replay, live feature
production/parity, completion joins, drift-triggered retraining and request-rate autoscaling remain
future work. Fresh verification reuses original artifacts; it does not repeat full training
or timed Kubernetes runs. Container images are identified in evidence and are not distributed
as release assets.
